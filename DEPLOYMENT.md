# Deployment Guide

This document explains how to deploy and use the PPT Cognitive Design Skill framework.

The framework is designed as:

an AI-native presentation intelligence system.

The framework can be integrated into:

- ChatGPT custom GPTs
- Codex workflows
- AI agent systems
- LLM orchestration frameworks
- educational AI assistants
- presentation generation pipelines

---

# Core Deployment Philosophy

The framework should function as:

a reasoning layer
for cognitively optimized presentation generation.

The framework is NOT intended to operate as:

a static template engine.

# Recommended LLM Behaviors

The deployed system should:

- reason before generating
- prioritize audience cognition
- optimize communication clarity
- simplify complexity progressively
- explain reasoning transparently
- reduce cognitive overload

Avoid:

- direct template dumping
- decorative over-generation
- unstable hierarchy
- uncontrolled complexity
