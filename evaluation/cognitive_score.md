# Cognitive Presentation Evaluation System

This system evaluates presentation quality from a cognitive perspective.

The goal is NOT visual beauty alone.

The goal is:

audience understanding efficiency.

---

# Core Evaluation Principle

A high-quality presentation should:

- reduce cognitive burden
- guide audience attention
- communicate progressively
- maintain narrative clarity
- stabilize visual rhythm

---

# Evaluation Dimensions

## 1. Cognitive Load

Evaluate:

- text density
- visual complexity
- information overload
- simultaneous concepts
- readability

### Failure Signals

- excessive paragraphs
- crowded layouts
- multiple focal points
- visual competition

---

## 2. Narrative Clarity

Evaluate:

- logical progression
- transition smoothness
- explanation rhythm
- section continuity

### Failure Signals

- abrupt topic changes
- disconnected slides
- unclear story progression

---

## 3. Visual Hierarchy

Evaluate:

- focal-point visibility
- hierarchy clarity
- reading direction
- emphasis structure

### Failure Signals

- equal visual emphasis
- unclear focus
- chaotic eye movement

---

## 4. Audience Adaptation

Evaluate:

- terminology suitability
- explanation depth
- diagram usage
- pacing appropriateness

### Failure Signals

- audience mismatch
- excessive abstraction
- over-technical explanation

---

## 5. Layout Stability

Evaluate:

- alignment consistency
- spacing rhythm
- visual grouping
- layout predictability

### Failure Signals

- unstable alignment
- irregular spacing
- scattered layout logic

---

## 6. Semantic Visual Consistency

Evaluate:

- color consistency
- visual language coherence
- icon consistency
- semantic mapping quality

### Failure Signals

- random color usage
- inconsistent style
- decorative overload

---

## 7. Presentation Rhythm

Evaluate:

- alternation of dense/light slides
- transition pacing
- summary placement
- cognitive breathing space

### Failure Signals

- continuous dense slides
- monotonous structure
- excessive repetition

---

---
# Evaluation Philosophy

A presentation succeeds when:

the audience understands effortlessly.

A presentation fails when:

the audience feels cognitively exhausted.


---
# Final Principle

Presentation quality is determined by:

cognitive communication efficiency

NOT:

visual decoration quantity.
