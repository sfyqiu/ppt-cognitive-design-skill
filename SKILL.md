# PPT Cognitive Design Skill

## Core Philosophy

PowerPoint is not page decoration.
PowerPoint is cognitive experience engineering.

## Workflow

1. Analyze scenario
2. Analyze user profile
3. Analyze audience
4. Extract valuable information
5. Build narrative structure
6. Classify slide types
7. Apply layout strategy
8. Map visual semantics
9. Optimize cognitive flow
10. Reduce cognitive overload

## Core Formula

One slide =
One problem +
One focal point +
One cognitive objective
