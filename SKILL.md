# PPT Cognitive Design Skill

## Purpose

This skill helps AI systems design PowerPoint presentations using:

- cognitive psychology
- audience-centered storytelling
- teaching-oriented communication
- semantic visual mapping
- presentation reasoning workflows

The goal is NOT slide beautification.

The goal is:

# audience understanding

---

# Core Design Logic

A presentation should:

- reduce cognitive burden
- guide audience attention
- reveal information progressively
- create semantic visual hierarchy
- emphasize teaching clarity

---

# Cognitive Design Rules

## Rule 1 — One Slide One Goal

Each slide should contain:

- one main idea
- one visual center
- one teaching objective

Avoid:

- multiple focal points
- excessive paragraphs
- overloaded charts

---

## Rule 2 — Audience First

Before designing slides, AI must infer:

- audience background
- expertise level
- attention span
- presentation scenario

Presentation complexity should adapt accordingly.

---

## Rule 3 — Visual Semantics

Colors are semantic signals.

Examples:

- blue → technology / GIS / remote sensing
- green → ecology / agriculture / vegetation
- orange → warning / emphasis
- gray → secondary information

Use color intentionally.

---

## Rule 4 — Cognitive Breathing Space

Slides should contain sufficient:

- margins
- spacing
- visual pauses
- empty regions

Avoid dense layouts.

---

## Rule 5 — Progressive Disclosure

Information should unfold progressively.

Recommended order:

1. problem
2. phenomenon
3. explanation
4. method
5. result
6. takeaway

---

# Teaching-oriented Presentation Strategy

For undergraduate teaching PPTs:

Prioritize:

- intuitive diagrams
- visual explanation
- simple language
- progressive understanding

Reduce:

- formula overload
- dense academic text
- excessive theoretical abstraction

---

# Interview Presentation Strategy

For teaching interviews:

The presentation should:

- establish credibility quickly
- demonstrate teaching ability
- reduce defensive questioning risk
- balance professionalism and accessibility

---

# Workflow Reasoning

AI should reason in the following order:

1. scenario analysis
2. audience modeling
3. presentation objective extraction
4. narrative structure planning
5. slide hierarchy design
6. visual semantic mapping
7. cognitive load optimization
8. final simplification

---

# Output Principles

AI-generated PPT structures should:

- minimize unnecessary text
- maximize semantic clarity
- maintain narrative rhythm
- avoid visual competition
- preserve audience attention

---

# Design Philosophy

Presentation design is:

- cognition engineering
- narrative engineering
- visual communication
- teaching psychology

NOT decoration.
