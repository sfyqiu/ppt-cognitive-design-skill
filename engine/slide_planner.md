# Slide Planner Engine

Slide planning transforms narrative logic into presentation structure.

A presentation should NOT be treated as a random collection of slides.

It should function as a cognitive progression system.

---

# Core Objective

Generate the optimal slide sequence based on:

- scenario
- audience
- narrative strategy
- presentation duration
- cognitive load
- teaching objectives

---

# Slide Planning Philosophy

The purpose of slide planning is NOT maximizing content quantity.

The purpose is:

maximizing audience understanding.

---

# Core Planning Logic

The slide planner should determine:

- total slide count
- slide categories
- narrative pacing
- information distribution
- visual rhythm
- cognitive transitions

---

# Standard Slide Categories

## 1. Opening Slides

Purpose:

- establish context
- gain attention
- reduce uncertainty
- establish credibility

Examples:

- cover
- agenda
- motivation
- key problem

---

## 2. Context Slides

Purpose:

- provide background
- align audience understanding
- introduce key concepts

Avoid:

- excessive theoretical density
- long paragraphs

---

## 3. Mechanism / Explanation Slides

Purpose:

- explain relationships
- reveal causality
- simplify complexity

Recommended:

- diagrams
- process flows
- semantic arrows
- progressive visuals

---

## 4. Evidence Slides

Purpose:

- prove claims
- validate reasoning
- support credibility

Examples:

- charts
- experimental results
- comparisons
- GIS maps

---

## 5. Transition Slides

Purpose:

- reset cognitive load
- summarize progress
- prepare next section

Characteristics:

- low density
- strong visual hierarchy
- concise messaging

---

## 6. Conclusion Slides

Purpose:

- reinforce memory
- simplify takeaways
- emphasize value

Recommended:

- key-message summary
- contribution summary
- future outlook

---

# Slide Count Strategy

## Short Presentation

5–10 slides

Requires:

- aggressive simplification
- visual emphasis
- compressed narrative

---

## Medium Presentation

10–20 slides

Allows:

- moderate explanation
- balanced rhythm
- guided storytelling

---

## Long-form Presentation

20–40 slides

Requires:

- narrative segmentation
- cognitive rhythm control
- transition reinforcement

---

# Educational Presentation Planning

For teaching-oriented presentations:

Prioritize:

- intuitive progression
- concept scaffolding
- visual reinforcement
- reduced abstraction

Avoid:

- early technical overload
- abstract-first explanation
- long theoretical blocks

---

# Academic Presentation Planning

Prioritize:

- research logic
- scientific validation
- evidence hierarchy
- contribution clarity

---

# Business Presentation Planning

Prioritize:

- persuasion
- emotional clarity
- value communication
- concise narrative

---

# Cognitive Rhythm Planning

Alternate between:

- dense explanation
- visual slides
- summaries
- diagrams
- reinforcement pages

Avoid:

- uninterrupted dense information
- excessive consecutive charts
- long text-only sequences

---

# Planning Failure Signals

Planning is failing if:

- audience loses orientation
- narrative pacing collapses
- sections feel disconnected
- too many concepts appear simultaneously
- presentation feels visually monotonous

---

# Final Principle

A presentation should feel like:

a guided experience.

Not:

a slide inventory.
