# Layout Selector Engine

Layout is cognitive structure visualization.

A good layout makes information understandable before reading begins.

---

# Core Philosophy

Layout is NOT decoration.

Layout controls:

- attention order
- reading direction
- visual hierarchy
- cognitive burden
- information rhythm

---

# Primary Objective

Select the optimal slide structure based on:

- content type
- audience cognition
- narrative objective
- information density
- visual complexity

---

# Layout Decision Logic

The layout engine should infer:

## 1. Information Density

Low-density slides:

- large visuals
- strong whitespace
- minimal text
- single focus

High-density slides:

- modular grouping
- hierarchy segmentation
- guided reading flow
- controlled complexity

---

## 2. Content Type

### Comparison Content

Recommended layouts:

- left-right comparison
- matrix comparison
- before-after structure

---

### Process Content

Recommended layouts:

- horizontal flow
- vertical sequence
- step-by-step pathway

---

### Scientific Mechanism

Recommended layouts:

- layered explanation
- central mechanism diagram
- cause-effect mapping

---

### Data-driven Slides

Recommended layouts:

- chart-centered
- minimal annotation
- guided takeaway emphasis

---

### Educational Slides

Recommended layouts:

- progressive reveal
- visual-first structure
- simplified hierarchy

---

# Cognitive Reading Direction

Recommended reading flow:

Top Left
↓
Top Right
↓
Center
↓
Bottom

Avoid:

- chaotic reading order
- visual competition
- unclear focal hierarchy

---

# Focal Point Rule

Every slide should contain:

- one dominant focal region
- one primary visual anchor
- one major takeaway

Avoid:

- equal-weight visual regions
- multiple competing charts
- text-heavy balance collapse

---

# Whitespace Strategy

Whitespace is cognitive breathing space.

Use whitespace to:

- reduce fatigue
- isolate concepts
- improve comprehension
- increase elegance

---

# Layout Complexity Levels

## Level 1 — Minimal

Use for:

- cover slides
- key messages
- strong conclusions

Characteristics:

- large typography
- large whitespace
- minimal objects

---

## Level 2 — Structured

Use for:

- educational explanation
- moderate information
- workflows

Characteristics:

- grouped modules
- guided hierarchy
- balanced visuals

---

## Level 3 — Dense Analytical

Use for:

- expert audiences
- scientific evidence
- technical comparison

Characteristics:

- compressed layout
- strong segmentation
- controlled complexity

---

# Layout Failure Signals

A layout is failing if:

- audience cannot identify focus quickly
- reading order is ambiguous
- visuals compete equally
- text dominates the slide
- eye movement feels chaotic

---

# Final Principle

Good layouts reduce explanation effort.

Bad layouts increase cognitive burden.
