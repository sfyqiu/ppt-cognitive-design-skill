# Contributing

Thank you for your interest in contributing to the PPT Cognitive Design Skill framework.

This project explores:

AI-native presentation intelligence
for cognitively efficient communication.

The framework combines:

- cognitive reasoning
- audience adaptation
- narrative intelligence
- visual semantic systems
- explainable AI
- presentation optimization

Contributions are welcome from multiple disciplines.

---

# Core Philosophy

This project is NOT focused on:

- decorative PPT templates
- visual beautification only
- slide marketplace systems

The project focuses on:

presentation cognition,
communication intelligence,
and audience-centered AI reasoning.
