# Use Cases

This document demonstrates practical use cases of the PPT Cognitive Design Skill framework.

The framework is designed as:

an AI-native presentation intelligence system
for cognitively efficient communication.

The framework is NOT limited to:

teaching interview presentations.

It supports a wide range of presentation scenarios.

---

# 1. Teaching Interview Presentations

## Scenario

University teaching interviews
for undergraduate education.

## Framework Focus

- teaching clarity
- interdisciplinary positioning
- cognitive simplification
- diagram-based explanation
- questioning-risk reduction

## Typical Features

- low cognitive density
- progressive storytelling
- educational visuals
- restrained professionalism
