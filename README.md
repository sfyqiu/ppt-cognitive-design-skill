# PPT Cognitive Design Skill

A reusable cognitive-driven PowerPoint design workflow for Codex and AI agents.

## Features

- Scenario-aware PPT design
- Audience-oriented storytelling
- Cognitive-load optimization
- Visual semantic mapping
- Layout strategy engine

## Installation

```bash
mkdir -p ~/.codex/skills/ppt-cognitive-design-skill
```

Copy the repository into the folder.

## Usage

Use ppt-cognitive-design-skill to redesign or generate presentations.
