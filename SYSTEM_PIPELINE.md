# SYSTEM PIPELINE

This document defines the global reasoning pipeline of the PPT Cognitive Design Skill system.

The pipeline transforms:

raw user requests

into:

cognitively optimized presentation systems.

---

# Global Objective

The system should:

- understand the real presentation objective
- infer audience cognition
- build narrative structure
- select proper layouts
- optimize cognitive load
- generate visually semantic slides
- refine presentation rhythm

The goal is NOT slide decoration.

The goal is:

audience understanding.

---

# Full Pipeline

```text
User Request
    ↓
Requirement Parser
    ↓
Scenario Reasoning
    ↓
Audience Reasoning
    ↓
Narrative Engine
    ↓
Slide Planner
    ↓
Layout Selector
    ↓
Visual Semantics Engine
    ↓
Cognitive Load Optimization
    ↓
Final Optimizer
    ↓
Presentation Output
```
---

# Pipeline Stage Details

## 1. Requirement Parser

Responsible for:

- extracting hidden goals
- identifying constraints
- inferring presentation type
- identifying risks
- recognizing content types

Output:

structured presentation conditions.

---

## 2. Scenario Reasoning

Responsible for:

- understanding presentation context
- determining narrative rhythm
- selecting professionalism level
- inferring presentation expectations

Examples:

- teaching interview
- defense presentation
- business pitch
- academic lecture

---

## 3. Audience Reasoning

Responsible for:

- expertise estimation
- cognitive tolerance estimation
- terminology control
- explanation depth adjustment

Audience cognition determines presentation complexity.

---

## 4. Narrative Engine

Responsible for:

- storyline construction
- information ordering
- progressive disclosure
- narrative pacing
- emotional progression

The narrative engine controls:

presentation readability.

---

## 5. Slide Planner

Responsible for:

- slide hierarchy
- section planning
- slide sequencing
- transition strategy
- cognitive pacing

The planner converts narrative into presentation structure.

---

## 6. Layout Selector

Responsible for:

- choosing layout patterns
- matching content with layout
- controlling visual density
- maintaining hierarchy clarity

Layout should support cognition.

---

## 7. Visual Semantics Engine

Responsible for:

- semantic color strategy
- visual emphasis
- spacing semantics
- icon meaning
- visual rhythm

Visual elements must communicate meaning.

---

## 8. Cognitive Load Optimization

Responsible for:

- reducing overload
- simplifying structure
- removing unnecessary information
- improving readability
- stabilizing visual hierarchy

Optimization reduces audience fatigue.

---

## 9. Final Optimizer

Responsible for:

- final simplification
- rhythm refinement
- narrative continuity
- visual consistency
- presentation polish

The final optimizer transforms:

functional slides

into

professional presentation systems.

---

# Core Philosophy

The system should think like:

- a teacher
- a cognitive psychologist
- a narrative designer
- a visual communicator
- a presentation strategist

NOT merely:

a slide beautification tool.

---

# Final Principle

Presentation intelligence is:

the ability to help audiences understand complex information effortlessly.
