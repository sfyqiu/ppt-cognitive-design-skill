# Teaching Interview PPT Design Case

## Scenario

University teaching interview presentation.

Target:
- demonstrate teaching ability
- establish professional credibility
- match remote sensing / GIS related disciplines

Presentation type:
- teaching interview
- undergraduate-oriented
- academic + teaching mixed presentation

---

# User Profile

Background:
- Agricultural Engineering
- Agricultural Water and Soil Engineering

Strengths:
- crop cultivation
- field experiments
- agricultural modeling
- machine learning applications

Weaknesses:
- not a pure remote sensing specialist
- avoid over-theoretical remote sensing explanation

Core strategy:
Use remote sensing as a tool
to solve agricultural problems.

---

# Audience Analysis

Audience:
- interview experts
- university faculty
- undergraduate teaching evaluators

Audience expectations:
- teaching clarity
- logical explanation
- professional structure
- discipline matching

Avoid:
- excessive theoretical derivation
- dense academic slides
- overly complex remote sensing terminology

---

# Design Strategy

Core design philosophy:

"Use agriculture as the foundation,
and remote sensing as enhancement."

Presentation should feel:
- teachable
- visual
- easy to follow
- structurally clear

---

# Visual Semantic Strategy

Main color:
- green (agriculture, vegetation)

Secondary color:
- blue (GIS, remote sensing, institutional identity)

Rule:
Green remains dominant.
Blue is used as supportive semantic color.

---

# Cognitive Structure

Preferred narrative structure:

Problem
→ Why remote sensing matters
→ Principle
→ Method
→ Agricultural case
→ Result
→ Conclusion

---

# Cover Slide Strategy

Structure:
- large agricultural background
- NDVI-style remote sensing map
- satellite imagery element
- strong visual center
- large clean title

Visual goals:
- combine agriculture + remote sensing
- reduce academic pressure
- establish teaching atmosphere

---

# Teaching Slide Strategy

Teaching slides should:
- reduce text
- use diagrams
- explain visually
- prioritize understanding

Each slide:
- one focal point
- one cognitive objective
- one key takeaway

---

# Cognitive Load Reduction

Rules:
- reduce unnecessary formulas
- reduce excessive bullet points
- avoid overloaded layouts

Target:
Audience should understand
main idea within 3 seconds.

---

# Key Design Insight

The PPT should NOT attempt
to pretend the user is
a pure remote sensing expert.

Instead:
present the user as:

"Agricultural engineering researcher
with remote sensing application ability."

This positioning is more authentic,
more stable,
and more convincing.

---

# Final Outcome

Presentation achieved:
- stronger teaching feeling
- better discipline alignment
- lower cognitive pressure
- clearer narrative structure
- stronger interview suitability
